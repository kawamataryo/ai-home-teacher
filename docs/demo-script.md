# デモ動画の台本（3分）

審査でいちばん効くのは「子どもが声で聞いて、先生が答えを言わずにヒントと図で導き、子どもが自分で解けた瞬間」。そこに時間を使う。

## 準備

- iPad を机のスタンドに立て、手元のノートが映る向きにする（設定でカメラを選ぶ）
- 撮影用の問題：割合の文章題を1問、ノートに手書き（例：「クラスの40%にあたる12人がめがねをかけています。クラスは何人？」）
- 画面収録：iPad のコントロールセンター → 画面収録（マイクをオン）。または Mac の QuickTime で iPad をつないで収録
- 1回目に前回の記録ができるよう、本番の前に一度だけ短いセッションをしておく（「前回の続き」を見せるため）
- 親のダッシュボードをスマホで開いておく

## 構成

| 時間 | 画面 | 話すこと・やること |
| --- | --- | --- |
| 0:00–0:20 | タイトル → 作者の家の朝（イメージでよい） | 「共働きのわが家。勉強の時間はあるのに、その時間に親は見てあげられない。一人で勉強するのは孤独です」 |
| 0:20–0:35 | iPad の学習画面 | 「勉強スタート」と声で言う → 先生が「昨日の割合の続きやる？」と前回のことに触れる |
| 0:35–1:20 | 先生と黒板 | 「ねえ先生、これ見て」→ カウントダウンで撮影 →「ちょっと考えるね」→ 黒板に手順カード。子どもが「答え教えて」と言っても、先生は答えを言わずに次のヒントへ |
| 1:20–1:45 | 割り込み | 先生が説明している途中で「待って、もう一回」→ すぐ止まって聞き直す |
| 1:45–2:05 | 自力で解ける | 子どもが答えを言う → 先生がほめる・口が動く・表情が変わる |
| 2:05–2:25 | 休憩の声かけ | タイマーの区切りで「そろそろ休憩しよっか」。休憩中の雑談を少し |
| 2:25–2:45 | 親のダッシュボード（スマホ） | 学習時間、取り組んだ問題、先生のひとこと |
| 2:45–3:00 | 構成図 | 「会話は Haiku、問題の読み取りと図は Sonnet、速い判断は Jev。写真と声は保存しません」→ 締め：「一人じゃない勉強を、どの家庭にも」 |

## 撮影のコツ

- 先生の声がよく聞こえるよう、静かな部屋で。iPad の音量は大きめ
- 失敗してもよい。止めて「勉強スタート」からやり直せる
- 「イベント中に作ったもの」が分かるよう、最後に GitHub のコミット履歴や issue の一覧を2秒だけ映す
