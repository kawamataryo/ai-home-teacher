## テーマ（いずれかを表現する）

いずれも「暮らす地域の課題を Claude Code で解決する取り組み」という位置づけ。

### テーマ1：あなたにしかない深さを。

自分が一番よく知っている世界（仕事・職場・地元・技術・趣味）を出発点に、その世界の仲間・地域の人・後継者が実際に使うものを作る。中にいる人だからこそ気づける「足りないもの」を見つける。

- ベテランの仕事のやり方を、本人が現場にいるうちに次の人が受け継げる形にする
- 自分の経験や感覚を、まだ誰も見たことのない形にする
- 「そういうものだ」と諦められてきた日々の不便を解消する

### テーマ2：本来、誰にでも届くべきものを。

専門知識・費用・言語・手続きといった壁を取り払い、一部の人にしか届いていないものを届ける。壁の外側にいる**具体的なひとり**を思い浮かべる。高齢化・人手不足・災害への備えなど日本社会の課題も対象。

- 専門家に頼れる人しか使えなかった手段を、誰でも使えるものにする
- 読めずに諦められてきた書類や案内を、誰にでも分かる言葉にする
- 人が減っていく地域でも、暮らしと備えを続けられる仕組みをつくる

## ルール

- チームは最大2名（1人参加可）。全員が応募・承認済みであること
- リポジトリは**公開**必須
- **新規制作のみ**。既存プロジェクトの再利用は不可。期間中の貢献が判別できないと失格
- デモ動画では期間中に作った機能・コードのみを紹介する（判別不能なら失格）
- 法令・倫理・プラットフォームポリシー違反、権利のない素材の利用は失格
- 提出物を含め、すべて日本語
