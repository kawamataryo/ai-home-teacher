# 黒板の部品カタログ

先生の話と一緒に、iPad の黒板（BoardView）に図を出せる。
`show_board` ツールで、下の部品から1つ選んで中身を指定する。
カタログで表せないときだけ `render_svg` ツールで SVG を描く。

> JSON の正確な形（フィールド名・型・必須かどうか）は、アプリ側の Swift のツール定義（`show_board` の JSON Schema）が正。
> このファイルは「どの部品をいつ使うか」の説明で、下に書くフィールドは目安。食い違ったらツール定義に従う。

## 共通のルール

- 黒板は答えを見せる場所ではない。正答・答えの数字・完成した作文を黒板に書かない
  - 答えが入る場所は空欄（「？」）にして、子どもに埋めてもらう
- 1回に出す部品は1つ。話している内容と合うものを選ぶ
- 文字は短く、小5が読める言葉にする。1つのラベルはだいたい15文字以内
- 図を出したら、話でも「黒板を見てね」とひと言ふれる
- 撮影した問題を使うときは、問題にある数・言葉をそのまま使い、勝手に変えない

## 部品

### step_cards（手順カード）

解き方や考え方の順番を、カードで見せる。ヒントの段階4（一緒にたどる）でよく使う。

- `title`: 見出し
- `steps`: カードの配列。各カードに `text`（短い説明）と、任意で `done`（終わったか）
- 最後のカード（答えを出すところ）は「？」のままにする

### number_line（数直線）

数の大小、分数・小数、割合、時間の流れを見せる。

- `min` / `max`: 範囲
- `ticks`: 目盛りの間隔
- `marks`: 印の配列。各印に `value`（位置）と `label`（ラベル）。答えの位置は `label: "？"` にする

### area_diagram（面積図）

かけ算・割合・平均・つるかめ算など、「1つ分 × いくつ分」を長方形の面積で見せる。

- `rects`: 長方形の配列。各長方形に `width` と `height` の値、`widthLabel` / `heightLabel`、任意で `areaLabel`
- 求めたい値のラベルは「？」にする

### segment_diagram（線分図）

和差算・割合・比など、量の関係を線分の長さで見せる。

- `segments`: 線分の配列。各線分に `label`（何の量か）と `parts`（区切り。各区切りに `length` と `label`）
- 線分どうしの差や合計を示す `braces`（範囲とラベル）を任意で付ける

### table（表）

資料の数をまとめ直す、条件を整理する、きまりを探すときに使う。

- `columns`: 列の見出し
- `rows`: 行の配列（各行はセルの文字の配列）
- `highlight`: 注目させたいセル（行と列の番号）の配列。答えのセルは「？」にする

### bar_chart（棒グラフ）

資料の数を比べやすくする。撮影したグラフを読みやすく描き直すときにも使う。

- `title`、`unit`（単位）
- `bars`: 棒の配列。各棒に `label` と `value`、任意で `highlight`（目立たせる）

### highlight_image（撮影画像の一部を囲む）

撮影した問題・資料の「どこを見ればよいか」を示す。ヒントの段階2（注目する場所）でよく使う。

- `regions`: 囲む場所の配列。各場所は画像に対する割合（0〜1）の `x` / `y` / `width` / `height` と、短い `label`
- 画像そのものは端末にあるものを使う。画像を送り返したり、作ったりしない

### essay_outline（作文の構成メモ）

作文の「はじめ・なか・おわり」を整理する。作文の段階1・2で使う。

- `theme`: 題
- `sections`: 段落の配列。各段落に `heading`（はじめ・なか・おわり など）と `notes`（子どもが話したことのメモ）
- `notes` には子どもが言ったことだけを書く。先生が考えた文章を入れない

## render_svg（カタログで表せないとき）

立体図形、図形の移動、てこ・ふりこ、地図の方角など、上の部品で表せないときだけ使う。

- 自己完結の SVG 1つだけを出す。`<svg>` の外に何も書かない
- `viewBox` を必ず指定する（例：`viewBox="0 0 800 600"`）。`width` / `height` は固定しない
- 外部リソースを使わない（画像・フォント・リンク・`<use href="http...">` など）
- `<script>`、`on〜` 属性（onclick など）、`<foreignObject>` は使わない
- 動かしたいときは CSS アニメーション（`<style>` 内の `@keyframes`）だけを使う
- 文字は大きめに（`font-size` 24 以上が目安）。色は黒板に映える明るい色を使う
- 答えの数や完成形は描かない。答えのところは「？」にする
